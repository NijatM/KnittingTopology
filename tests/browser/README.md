# Browser verification

Run `npm run dev` in one terminal, then `npm run test:browser` against the configured local app. Playwright launches its own fresh headless Chrome process and isolated contexts; it never attaches to user browser sessions. No browser installation is required on the verified machine.

`playwright.config.ts` uses the installed executable `/Applications/Google Chrome.app/Contents/MacOS/Google Chrome`, viewport 1440×1000, one worker, no retries, and arguments `--no-sandbox --use-gl=angle --use-angle=swiftshader --enable-unsafe-swiftshader`. `KNITTING_CHROME` overrides the executable; `KNITTING_BASE_URL` overrides the default `http://127.0.0.1:5173/KnittingTopology/`. `KNITTING_GPU=hardware` removes all GPU overrides, retaining only `--no-sandbox`.

Seven workspace tests check real UI interactions and workers: initial generation and surface changes with Euler/components/boundary assertions; actual pointer guide attachments and stale-result UI; node/cell selection returning recorded IDs; keyboard and button undo/redo restoring explicit graph content; downloaded project reload into a fresh context preserving graph IDs/content; OBJ/SVG/CSV/PNG download contents; supported 3–6-sided patches and five derived families; unsupported boundary counts retaining the previous accepted graph; comparison capture/restore; and 375px document overflow, help and generation controls.

The worker race test uses real numerical workers and their real results. It delays only delivery of completed result messages by one second so cancellation and obsolete input handling can be tested deterministically on fast machines. It does not synthesize results or replace numerical algorithms.

The earlier workspace baseline passed all seven tests in 56.1 seconds with no page or console errors. SHA256 snapshots of all source modules/styles before and after that run were identical. Current complete-suite results are recorded in [the verification record](../../docs/verification.md).

Screenshots and the current HTML report are under ignored `tmp/qa/`. Desktop, sphere atlas seams, selection, comparison and full-page 375px mobile screenshots were visually inspected. Separate isolated headless Chrome checks without GPU overrides confirmed native WebGL2: `ANGLE (Apple, ANGLE Metal Renderer: Apple M2 Pro, Unspecified Version)` with no context loss or console/page errors. Native and SwiftShader screenshots were inspected after a viewer-only sphere line visibility repair; scientific sphere drawing attachments still had maximum radius error 1.3877787807814457e-17 m at radius0.09m and cube selection returned an existing stable ID in both renderers.

Limits: Chrome on this Mac and software rendering do not establish other browser/GPU support. The mobile test resizes a desktop browser and does not establish physical touch-device behavior. No manual screen-reader or color-contrast audit was performed. These are software and geometric interaction checks, not scientific paper reproduction or physical validation.

`node tests/browser/camera-check.mjs` is a separate native-GPU camera probe. It intercepts only real WebGL uniform uploads in an isolated test browser, checks finite model-view transforms, unit rotation determinant, unchanged camera distance, and bounded roll during a small orbit from top. The verified top/orbit distances were both 0.4423036873 m and determinants within 5e-8 of1; screenshots were inspected with no errors. The production viewer contains no test/debug camera hook.

Four additional learning tests cover all 13 topics and actual Base/Overlay/Result diagrams, browsing without scientific-state changes, citation links and metadata, selectable clipboard fallback, BibTeX/CSL downloads, undoable input-only examples, a 375px layout, accepted-versus-pending descriptions, and generating-spacing statistics after cache restore and file import. The current full-suite results are recorded in [the verification record](../../docs/verification.md).

Five import tests cover OBJ units/offset/index identities, reversed-winding double-sided triangle selection, disabled generation/drawing, undo/redo, ASCII and solid-header binary STL, unit scaling, locally eligible signed volume, worker analysis after cache/file restore, invalid-file preservation, cancelled file reads, cancelled result delivery, revision changes and 375px overflow. Cancellation tests delay only real file reads and real worker result delivery; they do not synthesize meshes or analysis reports. A collapsed-tetrahedron regression verifies separate incidence counts and dimensionally correct count/tolerance units. Synthetic small OBJ/STL fixtures live in `tests/fixtures/import/`.

# Geometry

Implement surface geometry, topology-aware preprocessing and numerical primitives.

Own geometry routines only for assigned tasks. State mesh preconditions, units, orientation and boundary behavior. Preserve intentional holes and layers. Validate curvature and geometry with analytic/reference cases, dimensional scaling and refinement as appropriate. Keep the core independent of the renderer and UI. Return explicit degeneracy diagnostics and geometry revision changes; do not silently delete features to make a mesh acceptable.

Expected handoff: Geometry implementation, numerical checks and a short precondition/limitation report.

Use `templates/result.json` and the relevant project skill. Read `AGENTS.md`, the task and owned inputs first.

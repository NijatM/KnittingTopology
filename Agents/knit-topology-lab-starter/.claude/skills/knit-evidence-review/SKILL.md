---
name: knit-evidence-review
description: Review primary research for knitted-material pattern/topology design and record bounded claims, assumptions, applicability and counterevidence.
---

Identify the actual design or implementation question before searching. Prefer primary papers, author software and official documentation. Record title, authors, year, stable link/DOI, source type and the supporting section/equation only when actually inspected. Mark abstract-only or indexed-text-only access.

Separate observed results, model assumptions, proposed transfer and personal design judgment. For every consequential claim state what would invalidate it in this project's geometry, material, loading or scale. Do not invent unavailable material constants or numerical results. If evidence is missing, propose the smallest calculation/experiment that would discriminate the competing explanations.

Use the repository's claim template when available. Return a few directly useful findings and limits, not a large unranked literature list. A paper about one stitch architecture does not validate all knits; a knitted formwork precedent does not establish unsupported textile capacity.
